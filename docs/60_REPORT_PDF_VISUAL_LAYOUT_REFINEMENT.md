# 60_REPORT_PDF_VISUAL_LAYOUT_REFINEMENT

## Objetivo
Refinar o layout visual do PDF de relatórios para sair com aparência mais consistente e previsível.

## O que mudou
- A4 paisagem mantido
- 2 relatórios por página mantido
- relatórios lado a lado mantido
- blocos agora usam toda a largura útil da coluna
- título do cabeçalho em destaque
- caixa de metadados no topo direito de cada relatório
- corpo com espaçamento e leitura mais confortável
- rodapé centralizado, preparado para cidade/data e linha de assinatura
- preview da página no admin agora simula os 2 relatórios lado a lado

## Regras visuais aplicadas
- primeira linha do cabeçalho sai com mais destaque
- linhas seguintes do cabeçalho saem como detalhes institucionais
- corpo respeita a ordem exata do template com TAGS
- rodapé mantém texto fixo e aceita linha de assinatura com underscores

## Assunções adotadas
- sem logo neste passo
- sem HTML rico neste passo
- template continua em texto livre com TAGS
